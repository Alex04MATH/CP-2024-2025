3. ### [Ciclos](/Ciclos/)
    
   CP#3 Programación iterativa ejercicios relacionados con bucles, recorrer array, buscar en array.
    - ejemplo de declaraciones de Ciclos:
    ```csharp
       while(true) // Se ejecuta solo cuando la condicion es verdadera ejecuta entre:(0 o ♾️) dependiendo de al condicion.  
       {

       }

       do
       {

       }while(<condition>) // Se diferencia al while en que su ejecución es entre (1 o ♾️).

       for(<initiation>;<condition>;<update>) // While, su difencia esta en inicializar tipos y actualizarlos en cada iteración
       {

       }

       foreach(<Tipe> identifier in <Tipe1>) //identifier recorre elementos de Tipe1 si contiene definición de extención o instancia
       {

       }
    ```
